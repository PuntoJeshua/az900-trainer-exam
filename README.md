**Entrenador AZ-900** es una plataforma web moderna, rápida y altamente optimizada diseñada para ayudarte a aprobar el examen de certificación **Microsoft Azure Fundamentals (AZ-900)** en tu primer intento. 

Este sistema no es solo un simulador; es un **entrenador inteligente** que analiza tus debilidades y te guía en un estudio dirigido.

---

## ✨ Características Principales

### 🧠 Estudio Inteligente
- **🎯 Ataque de Debilidades**: Algoritmo que detecta automáticamente tus dominios con menor puntaje y genera sesiones de práctica enfocadas.
- **📊 Medidor de Confianza**: Evalúa tu seguridad en cada respuesta para diferenciar entre lo que sabes y lo que adivinaste.
- **🔄 Repaso de Errores**: Filtro dinámico para practicar únicamente las preguntas que has fallado anteriormente.

### 🛠 Herramientas de Aprendizaje
- **🗂 Flashcards**: Tarjetas interactivas con efecto 3D para memorizar conceptos clave de forma rápida.
- **📖 Glosario Buscable**: Encuentra cualquier concepto o pregunta instantáneamente por palabra clave.
- **📑 Marcadores**: Guarda preguntas complejas para revisarlas profundamente más tarde.
- **🔗 Microsoft Learn Integrado**: Enlaces directos a la documentación oficial en cada explicación.

### 🏁 Simulación Realista
- **⏱ Modo Examen**: Temporizador de 60 minutos, navegación fluida y marcado de preguntas para revisión, imitando la interfaz real de Pearson VUE.
- **📉 Estadísticas Detalladas**: Visualización de maestría por dominio mediante gráficos interactivos y seguimiento de progreso histórico.

## 🛠️ Instalación y Uso

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/az900-trainer.git
   cd az900-trainer
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar en desarrollo:**
   ```bash
   npm run dev
   ```

4. **Construir para producción:**
   ```bash
   npm run build
   ```
